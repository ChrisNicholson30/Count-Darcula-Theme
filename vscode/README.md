# Count Darcula — VS Code

A hybrid of One Dark and Dracula. Every syntax colour sits at one perceptual lightness, every
body-text colour passes WCAG AA on the surface it renders on, and the true-black **Nocturne**
variant cuts modelled OLED panel power by ~48%.

Four variants: **Count Darcula**, **Count Darcula Bloodline** (the special edition — same
discipline, spent on the Dracula side of the family, over a darker canvas), **Count Darcula
Nocturne** (OLED), **Count Darcula Daylight**.
Pick one with <kbd>Ctrl</kbd>+<kbd>K</kbd> <kbd>Ctrl</kbd>+<kbd>T</kbd>.

Works the same in Cursor, Windsurf and VSCodium — a colour theme is data the workbench reads,
not code it runs.

- **Website:** https://countdarcula.com
- **Source, install instructions and the accessibility report:**
  https://github.com/ChrisNicholson30/Count-Darcula-Theme

The files in `themes/` are generated from `src/palette.js` in the repository above. Edit the
palette, not the JSON.
